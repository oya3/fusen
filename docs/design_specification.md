# 付箋アプリ（Fusen） 設計仕様書

## 1. 概要・コンセプト

本アプリケーションは、Windows 11のデスクトップ環境で動作する、**超軽量・シンプル・完全ポータブル**な付箋（Sticky Notes）アプリケーションです。

### コアコンセプト
1. **完全ポータブル（システム非侵食）**:
   - レジストリや `%APPDATA%` などのWindowsシステム領域を一切汚さず、アプリ直下の `data/` ディレクトリ内にすべてのデータ・画像を完結して保存。
   - フォルダごと移動（USBメモリや別ドライブ等）しても、そのまま以前の状態で動作可能。
2. **極めて軽量・シンプル**:
   - 余計な装飾や重厚なフレームワークを排し、瞬時の起動と最小限のメモリフットプリントを実現。
3. **スマートな省スペース表示（1行目タイトル折りたたみ）**:
   - 1行目のテキストのみを表示する「薄型スリムバー」にワンクリックで切り替え可能。
   - デスクトップの邪魔にならず、見たいときだけ即座に展開。
4. **画像貼り付けのネイティブ対応**:
   - スクリーンショットやクリップボード画像を `Ctrl + V` でそのまま付箋内にインライン貼り付け。
5. **メモ一覧管理画面（マネージャー）**:
   - 付箋が多くなった場合でも一覧画面から素早く検索・フォーカス・デスクトップから剥がす（削除・非表示）が可能。

## 2. 機能要件一覧

| 機能分類 | 機能名 | 仕様概要 |
| :--- | :--- | :--- |
| **表示・操作** | **タイトル折りたたみ / 展開** | 1行目のみを表示するスリムバーと全面表示をワンクリック/ダブルクリックで切り替え。 |
| | **ドラッグ移動 & リサイズ** | ヘッダーをドラッグしてデスクトップの任意位置へ移動。端をドラッグして自由なサイズに変更。 |
| | **最前面固定（ピン留め）** | 他のアプリの前面に常に固定表示するモードのON/OFF切り替え（付箋ごとに個別設定可）。 |
| | **カラーテーマ変更** | パステル調の付箋カラー（イエロー、グリーン、ブルー、ピンク、パープル、ダーク）の切り替え。 |
| **編集・入力** | **テキスト入力** | プレーンテキスト / リッチテキストの編集。1行目が自動的に折りたたみ時のタイトルになる。 |
| | **画像貼り付け** | クリップボードの画像を `Ctrl + V` で本文にインライン貼り付け。画像は `data/images/` に自動保存。 |
| **データ・管理**| **完全自動保存** | テキスト入力、移動、リサイズ、折りたたみ、色変更をリアルタイムに自動保存。 |
| | **状態の完全復元** | 起動時に、各付箋の配置座標、サイズ、展開/折りたたみ状態、カラー、内容を完全復元。 |
| | **複数付箋の管理** | デスクトップ上に**何枚でも同時に付箋を配置可能**。それぞれ独立して位置・サイズ・色・内容を保持。 |
| | **メモ一覧管理画面** | すべての付箋をリスト/カードで一覧表示。キーワード検索、デスクトップからの剥がし（削除/非表示）、該当付箋へのジャンプ、一括折りたたみ/展開。 |
| **常駐・追加** | **タスクトレイ常駐** | レジストリを汚さずに時計横（トレイ）に常駐。クリック/右クリックメニューから新規付箋作成や一覧表示が可能。付箋が0枚になってもトレイから新規作成可能。 |
| | **付箋上からの追加** | 各付箋のヘッダーにある `＋` ボタンや `Ctrl + N` でも隣に新しい付箋を即時追加可能。 |
| **システム** | **ポータブル動作** | すべての設定・画像データをアプリ実行ディレクトリ配下の `data/` に格納。 |

## 4. UI / UX 仕様

### 4.1. 付箋ウィンドウ（NoteWindow）
* **スタイル**: 枠なし（`WindowStyle="None"`, `AllowsTransparency="True"`）、角丸（CornerRadius: 8px）、Windows 11調のドロップシャドウ。
* **ヘッダー部（ツールバー）**:
  * `＋` : 新しい付箋を追加（`Ctrl + N`）
  * `📌` : 最前面固定（ピン留め）トグル
  * `🎨` : カラーパレット選択
  * `📋` : メモ一覧管理画面を開く（`Ctrl + L`）
  * `▲ / ▼` : 折りたたみ（スリムタイトルバー化）/ 展開切り替え
  * `✕` : 付箋削除（デスクトップから剥がす）
* **折りたたみ表示（省スペースモード）**:
  * 折りたたみ時は高さが約38pxのスリムバーに変形。
  * 1行目のテキストのみがタイトルとして表示される。
  * ダブルクリックまたは `▲/▼` ボタンで前回のサイズへ即座に復元。
* **本文領域**:
  * `RichTextBox` によるテキスト編集 & 画像インライン表示。
  * `Ctrl + V` でクリップボードの画像を直接貼り付け。

### 4.2. メモ一覧管理画面（NoteListWindow）
* **検索バー**: 上部の検索窓に文字を入力すると、タイトルおよび本文からリアルタイムに絞り込み。
* **メモ一覧カード**:
  * 各付箋のテーマカラー、タイトル（1行目）、本文プレビュー、更新日時を表示。
  * **「剥がす（削除）」ボタン**: 一覧から該当の付箋を削除。
  * **「表示 / 非表示」切り替え**: デスクトップから一時的に剥がして保管、または再表示。
  * **ダブルクリック / フォーカス**: デスクトップ上のその付箋の位置へ移動・最前面化・展開。
* **一括アクション**:
  * 「＋ 新規付箋作成」
  * 「すべて折りたたむ」/「すべて展開する」

### 4.3. タスクトレイ（NotifyIcon）常駐
* 時計の横（タスクトレイ）にアイコンを常駐。
* **左クリック**: 新しい付箋を画面中央に作成。
* **右クリックメニュー**:
  * 📝 新しい付箋を作成
  * 📋 メモ一覧を開く
  * 📂 保存先データフォルダを開く
  * 🔼 すべて展開する / 🔽 すべて折りたたむ
  * 🚪 終了

## 6. 非機能要件・ポータブル方針

1. **ゼロ・システム侵食**:
   - レジストリ、`%APPDATA%` は一切不使用。
   - 実行ファイル（またはスクリプト）と同じディレクトリの `data/` 配下ですべて完結。
2. **Crash-safe な自動保存**:
   - `notes.json` 更新時は一時ファイル書き込み後にアトミックリネームを行い、破損を防ぐ。
   - デバウンス（300ms）による快適な入力レスポンス。
3. **完全なポータビリティ**:
   - フォルダを丸ごと別のPCやUSBメモリにコピーしても、設定やデータがそのまま移行可能。
