# fusen - Windows 11 超軽量デスクトップ付箋アプリ

Windows 11のデスクトップに貼り付けられる、**超軽量・シンプル・完全ポータブル**な付箋（Sticky Notes）アプリケーションです。

---

## ✨ 主な特徴

- 🚀 **完全ポータブル（システム非侵食）**
  - Windowsのレジストリや `%APPDATA%` は一切使用しません。
  - すべての付箋データや貼り付けた画像は、アプリ直下の `data/` フォルダ内に保存されます。
  - フォルダごとUSBメモリや別ドライブに移動しても、そのまま利用可能です。
  - 唯一の例外が自動起動の設定で、これも `setup-autostart.bat` を実行したときだけショートカットを1つ置きます。
- 📌 **タイトル（1行目）のみ表示（折りたたみ / 展開）**
  - 1行目のテキストだけを表示する「薄型スリムバー」にワンクリックで変形。
  - デスクトップの端に並べても邪魔にならず、見たい時だけ即座に展開できます。
- 🖼️ **画像の貼り付け**
  - クリップボード（スクリーンショット等）から `Ctrl + V` で画像を付箋に貼り付け可能。
  - 画像ファイルは `data/images/` に保存され、本文には Markdown の画像記法 `![](images/xxx.png)` がテキストとして入ります。
    そのため手で書き換えたり、他の付箋にコピーしたりできます。
  - 右クリックメニューから画像のコピー・削除ができます。削除すると、どの付箋からも使われなくなった画像ファイルも一緒に片付きます。
- 👁 **Markdown プレビュー**
  - ヘッダーの `👁` ボタンで、本文を Markdown として描画した表示に切り替えられます（`✏` で編集へ戻る）。
  - 見出し・強調・リスト・引用・コードブロック・リンク・表に対応。貼り付けた画像もそのまま表示されます。
  - プレビュー中かどうかは付箋ごとに保存され、次回起動時も復元されます。
- ⌨️ **bash（Readline / Emacs）キーバインド — 既定で有効**
  - 本文編集で `Ctrl + A` / `Ctrl + E` / `Ctrl + K` などの操作が使えます。`Ctrl + S` / `Ctrl + R` のインクリメンタル検索も可能。
  - **既定で有効なため `Ctrl + N` は「1行下へ移動」になります。新規作成は `Alt + N` を使ってください。**
  - 不要な場合は `fusen.ini` の `[Bash] Enabled = false` で無効にできます。
- 📋 **メモ一覧マネージャー**
  - 付箋が多くなっても、一覧画面からキーワード検索、該当付箋へのジャンプ、デスクトップからの「剥がし（保管）」と貼り直しが一目で操作できます。
  - **付箋の完全削除はこの一覧画面からのみ**行えます（確認ダイアログあり）。付箋側の `✕` は剥がすだけなので、押し間違えても内容は失われません。
- ⚙️ **設定ファイル（`fusen.ini`）による初期値カスタマイズ & 半透明対応**
  - `fusen.exe` と同じフォルダにある `fusen.ini` から、新規作成時の初期サイズ（幅・高さ）、テーマカラー、不透明度、最前面固定、フォントなどを自由に変更可能。
  - **半透明（透過）指定に対応**:
    - ウィンドウ全体の不透明度指定（例: `Opacity = 0.85`）
    - 色コードでのアルファ透過指定（例: `#AARRGGBB` 形式で `Background = #D9FFFDE7` など）
  - トレイアイコンや一覧マネージャーからいつでもワンクリックで `fusen.ini` を開いて編集できます。
- 🔄 **完全自動保存 & 起動時の復元**
  - テキスト入力、移動、リサイズ、折りたたみ、色・不透明度・文字サイズの変更をリアルタイムに自動保存。
  - PC再起動時や次回起動時も前回の配置と状態をそのまま再現します。
- 🖥️ **マルチモニタでの取り残し防止**
  - 2画面目に貼った付箋は、その画面を外すと表示できる場所が無くなります。モニタの取り外しや解像度の変更を検知して、見えなくなった付箋を掴める位置へ自動的に引き戻します。
  - 引き戻した位置がそのまま保存されるため、**モニタを戻しても元の配置には復帰しません**。
- 🛟 **世代バックアップと自動復旧**
  - `data/notes.json` のコピーを `data/backups/` に世代保存（既定5世代）。
  - 万一ファイルが破損しても、起動時に最新の正常な世代から自動的に復旧します。
- 🔔 **タスクトレイ常駐**
  - 時計横のトレイアイコンをクリックするだけで、いつでも新しい付箋を作成できます。

## ⌨️ 操作方法 & ショートカット

### 付箋ウィンドウ上の操作
| 操作 / キー | 機能 |
| :--- | :--- |
| **ヘッダーのダブルクリック** | 折りたたみ / 展開 の切り替え（1行目タイトル化） |
| **ヘッダーのドラッグ** | 付箋の移動 |
| **8方向（端・角）ドラッグ** | 付箋のサイズ変更（折りたたみ中は左右のみ） |
| **`＋` ボタン / `Alt + N`** | 新しい付箋を作成（右下30pxの位置） |
| **`📌` ボタン** | 最前面固定（ピン留め）のON / OFF |
| **`🎨` ボタン** | 付箋カラー・**不透明度（20〜100%）**・**文字サイズ（9〜36）** の変更 |
| **`👁` / `✏` ボタン** | Markdownプレビュー / 編集 の切り替え |
| **`▲ / ▼` ボタン** | 折りたたみ / 展開 |
| **`✕` ボタン** | デスクトップから剥がして保管（内容は残り、メモ一覧から貼り直せます） |
| **`Ctrl + L`** | メモ一覧マネージャーを開く |

## ⚙️ 設定ファイル (`fusen.ini`)

`fusen.exe` と同じディレクトリに配置される `fusen.ini` で各種初期設定をカスタマイズできます。
ファイルが無い場合は既定内容で自動生成されます。変更後はアプリを再起動すると反映されます。

```ini
[Note]
; 新規作成時の付箋のデフォルト幅・高さ（ピクセル単位）
Width = 280
Height = 300

; 新規作成時のデフォルトテーマカラー (Yellow, Green, Blue, Pink, Purple, Dark, Custom)
ColorTheme = Yellow

; ウィンドウ全体の不透明度 (0.10 〜 1.00 または 10 〜 100 %)
Opacity = 0.85

; 新規作成時に最前面に固定するかどうか (true / false)
Pinned = false

; 本文のフォントサイズ（新規作成時の初期値。以後は付箋ごとに 🎨 から変更）
FontSize = 13.5

; 本文のフォントファミリー（全付箋共通）
FontFamily = Segoe UI, Yu Gothic UI, Meiryo

; ------------------------------------------------------------------------------
; [Backup] 世代バックアップ（data/notes.json を data/backups/ に世代保存）
; ------------------------------------------------------------------------------
[Backup]
Enabled = true
Generations = 5          ; 保持する世代数 (1 〜 100)
IntervalMinutes = 10     ; 稼働中の作成間隔（分）。起動時・終了時は必ず1世代作成

; ------------------------------------------------------------------------------
; [Bash] bash (Readline / Emacs) キーバインド
; ------------------------------------------------------------------------------
[Bash]
Enabled = true

; ------------------------------------------------------------------------------
; [CustomTheme] カスタムカラー設定（半透明対応）
; 色は #RRGGBB（通常）または #AARRGGBB（先頭2桁AAがアルファ透過度）で指定できます。
; ------------------------------------------------------------------------------
[CustomTheme]
DisplayName = カスタム
Background = #D9FFFDE7       ; 約85%不透明のイエロー（背景が透けます）
Header = #E6FFF59D           ; ヘッダー背景色
Border = #FFF176             ; 枠線色
Foreground = #212121         ; 本文文字色
HeaderForeground = #3E2723   ; ヘッダー文字色
```

既存テーマの色を部分的に上書きしたい場合は `[Theme.Yellow]` `[Theme.Dark]` のようなセクションを追加します。
存在しない名前を書けば、新しいテーマとしてカラーパレットに追加されます。

## 📂 ディレクトリ構成

```
fusen/
├── Fusen.slnx                    # ソリューション（.slnx 形式）
├── fusen.ini                     # 設定ファイル（初期サイズ・色・半透明・バックアップ設定等）
├── build.bat                     # 配布用パッケージのビルド（出力先 bin/publish）
├── run.bat                       # 開発実行（dotnet run）
├── setup-autostart.bat           # 自動起動の設定 / 解除
├── setup-autostart.ps1
├── docs/
│   └── design_specification.md   # 設計仕様書
├── data/                         # アプリデータ（完全ポータブル・Git管理外）
│   ├── notes.json                # 付箋データ（位置・サイズ・内容・設定）
│   ├── backups/                  # notes.json の世代バックアップ
│   └── images/                   # 貼り付けた画像ファイル (*.png)
├── bin/publish/                  # build.bat の出力先（Git管理外）
└── src/
    └── Fusen/                    # C# / WPF ソースコード
```

## 🛠️ ビルド & 実行方法

.NET 10 SDK が必要です（`net10.0-windows`）。

### 開発・デバッグ実行
```powershell
dotnet run --project src/Fusen/Fusen.csproj
```
または `run.bat` をダブルクリック。

### 配布用パッケージの発行
```powershell
dotnet publish src/Fusen/Fusen.csproj -c Release -o bin/publish
```
または `build.bat` を実行してください。

出力された `bin/publish/` フォルダを**丸ごと**コピーして配布・移動します
（`fusen.exe` のほかに `fusen.ini`、`Markdig.dll`、`setup-autostart.*` が含まれます）。
`.NET 10 ランタイム`がインストールされたPCで動作します。

## 🔁 自動起動（任意）

Windows のログオン時に fusen を起動させたい場合は、配布フォルダ内の `setup-autostart.bat` を実行してください。
実行したユーザーのスタートアップフォルダに `fusen.lnk` を1つ作成します。

解除するには PowerShell で次を実行します。

```powershell
.\setup-autostart.ps1 -Remove
```

既定では設定されません。アプリ自身が起動時・終了時にスタートアップへ書き込むことはありません。
