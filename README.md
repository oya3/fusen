# fusen - Windows 11 超軽量デスクトップ付箋アプリ

Windows 11のデスクトップに貼り付けられる、**超軽量・シンプル・完全ポータブル**な付箋（Sticky Notes）アプリケーションです。

---

## ✨ 主な特徴

- 🚀 **完全ポータブル（システム非侵食）**
  - Windowsのレジストリや `%APPDATA%` は一切使用しません。
  - すべての付箋データや貼り付けた画像は、アプリ直下の `data/` フォルダ内に保存されます。
  - フォルダごとUSBメモリや別ドライブに移動しても、そのまま利用可能です。
- 📌 **タイトル（1行目）のみ表示（折りたたみ / 展開）**
  - 1行目のテキストだけを表示する「薄型スリムバー」にワンクリックで変形。
  - デスクトップの端に並べても邪魔にならず、見たい時だけ即座に展開できます。
- 🖼️ **画像のインライン貼り付け**
  - クリップボード（スクリーンショット等）から `Ctrl + V` で画像を直接付箋内に貼り付け可能。
  - 画像は `data/images/` に自動保存され、次回起動時もそのまま復元されます。
- 📋 **メモ一覧マネージャー**
  - 付箋が多くなっても、一覧画面からキーワード検索、該当付箋へのジャンプ、デスクトップからの「剥がし（削除・保管）」が一目で操作できます。
- 🔄 **完全自動保存 & 起動時の復元**
  - テキスト入力、移動、リサイズ、折りたたみ、色変更をリアルタイムに自動保存。
  - PC再起動時や次回起動時も前回の配置と状態をそのまま再現します。
- 🔔 **タスクトレイ常駐**
  - 時計横のトレイアイコンをクリックするだけで、いつでも新しい付箋を作成できます。

## ⌨️ 操作方法 & ショートカット

### 付箋ウィンドウ上の操作
| 操作 / キー | 機能 |
| :--- | :--- |
| **ヘッダーのダブルクリック** | 折りたたみ / 展開 の切り替え（1行目タイトル化） |
| **ヘッダーのドラッグ** | 付箋の移動 |
| **右下端のドラッグ** | 付箋のサイズ変更（リサイズ） |
| **`＋` ボタン / `Ctrl + N`** | 新しい付箋を作成 |
| **`📌` ボタン** | 最前面固定（ピン留め）のON / OFF |
| **`🎨` ボタン** | 付箋カラーの変更（6色のパステル/ダークテーマ） |
| **`📋` ボタン / `Ctrl + L`** | メモ一覧マネージャーを開く |
| **`▲ / ▼` ボタン** | 折りたたみ / 展開 |
| **`✕` ボタン / `Ctrl + W`** | 付箋を剥がす（削除） |
| **`Ctrl + V`** | クリップボードのテキストまたは画像を貼り付け |

### タスクトレイ（通知領域）アイコン
| 操作 | 機能 |
| :--- | :--- |
| **左クリック** | 新しい付箋を作成 |
| **右クリック** | コンテキストメニュー（新規作成、一覧、データフォルダ、全展開/全折りたたみ、終了） |

## 📂 ディレクトリ構成

```
fusen/
├── fusen.exe                     # 実行ファイル（配布時）
├── data/                         # アプリデータ（完全ポータブル）
│   ├── notes.json                # 付箋データ（位置・サイズ・内容・設定）
│   └── images/                   # 貼り付けた画像ファイル
│       └── *.png
├── docs/
│   └── design_specification.md   # 設計仕様書
└── src/
    ├── Fusen.sln
    └── Fusen/                    # C# / WPF ソースコード
```

## 🛠️ ビルド & 実行方法

### 開発・デバッグ実行
```powershell
dotnet run --project src/Fusen/Fusen.csproj
```

### 配布用バイナリの発行（単一実行ファイル）
```powershell
# Framework-dependent 版（軽量・要.NET 10/8）
dotnet publish src/Fusen/Fusen.csproj -c Release -r win-x64 --no-self-contained -p:PublishSingleFile=true -o ./dist

# Self-contained 版（単体でどのPCでも動作）
dotnet publish src/Fusen/Fusen.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./dist
```

または付属の `build.bat` を実行してください。
